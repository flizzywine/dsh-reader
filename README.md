# dsh-reader

基于 DSH（DeepSeek Harness）的阅读器：**书在中间，Agent 对话在右栏**。

## 启动

第一次先跑一次：

```bash
./bin/setup-profile.sh
```

它会在 `~/.dsh/profiles/reader` 建好 profile，链接 `plugin/`，并把 `dsh-reader` 命令放到 `dsh` 旁边。之后用法和 `dsh-tavern` 一样：

```bash
dsh-reader start      # 启动，并在浏览器打开（已在运行就直接打开）
dsh-reader restart    # 改了宿主代码（plugin/*.js 里非 client.js 的部分）后重启，并重新打开页面
dsh-reader stop
dsh-reader status     # 是否在运行、访问地址
dsh-reader open       # 页面关了，重新打开
dsh-reader logs       # 最近的日志
```

- 端口固定为 `30160`，可以用 `DSH_READER_PORT` 改。
- 日志和 PID 记录在 `~/.dsh/profile-data/reader/service.log`、`service.json`。
- 每次启动 DSH 都会生成新的带 token 的地址。浏览器第一次用这个地址进来后会记住登录，之后直接开 `http://127.0.0.1:30160/` 也行，重启后刷新页面就能连上。
- 改 `client.js` 不用重启，刷新页面即可；改宿主代码要 `dsh-reader restart`。
- **手机访问**：profile 里装了 [dsh-pocket](https://github.com/shaobeichen/dsh-pocket)。在「设置 → 手机访问」扫二维码，手机和电脑连同一个 Wi-Fi 就能打开，地址是 `http://<电脑局域网 IP>:30161`，要输入访问密码；那一页也能开公网访问。dsh-tavern 的 pocket 占着 3081，所以这里用 30161，可以用 `DSH_READER_POCKET_PORT` 改。访问密码和 tavern 共用（都存在 `~/.dsh/dsh-pocket/`）。

## 用法

照 dsh-tavern 的结构：

- **左侧栏**（替换 DSH 原来的工作区列表）：
  - 「＋ 选择一本书 · 开始阅读」：选一本书，新开一个对话。书在中间，陪读 Agent 在右栏。
  - 「导入新书」：导入 TXT（UTF-8 或 GBK）、EPUB 或 PDF，会存进 `library/`。原文不进 git。EPUB、PDF 用书里的书名，只取文字，图片和排版样式不要；有 DRM 加密的 EPUB 读不了。文件名里下载站加的「(z-library…)」会去掉。
  - 「书库」：打开右栏的书库页。
  - 阅读历史：按书分组，每条显示读到第几节。
  - 底部是当前的工作台性格，点一下可以切换。
- **右侧栏页面**（也能从右栏「＋」打开）：
  - 「对话」：原生 DSH 对话。
  - 「书库」：每本书一张卡片，类似人物卡库。
  - 「工作台性格」：性格对所有阅读对话生效。
- **工作台性格**：沿用 dsh-tavern 卡片工作台的三个内置性格（猫娘助手·煮米、冷静专业编辑、毒舌吐槽役·阿刺），也可以选空白。性格可以在页面里编辑，也能恢复默认。选了性格时，DSH 自带的身份段落会被换掉，工具说明保留。
- **排版与阅读设置**：
  - 程序把原文整理成段落：去掉原有缩进、多余空行和 CRLF，统一首行缩进两字、两端对齐。正文里重复的章节标题去掉，「作者：… 更新：…」这类行排成小号灰字。
  - 阅读栏的「Aa」可以调主题（跟随界面 / 纸白 / 羊皮纸 / 护眼绿 / 夜间）、字体（宋体 / 楷体 / 黑体；装了霞鹜文楷会优先用它做楷体）、字号、行距、页宽。
  - 这些设置只存在当前浏览器。
- **皮肤**：沿用 dsh-tavern 内置的 dsh-dream-skin，包括赤陶（Terracotta）配色、壁纸和换肤入口（在「设置」里）。`setup-profile.sh` 会从旁边的 `dsh-tavern` 仓库链接这份皮肤（可以用 `DSH_TAVERN_ROOT` 改路径），找不到就用 DSH 自带主题。所以皮肤跟着 dsh-tavern 的版本走。阅读主题选「跟随界面」时，正文配色跟皮肤一致。
- **书详情**：在书库里点书名，进入这本书的详情页：字数、节数，正在读时还有阅读进度。下面分三页：「高亮」列出所有划线，「笔记」先列随想，再列写在划线上的想法，「总结」按节列出 Agent 写的总结，可以全部展开或收起。都按章分组；正在读这本书时，点定位图标能在阅读区跳到那一段（总结是打开那一节）。「总结文件夹」会在 Finder 里打开 `library/<书名>/总结/`，方便手改。
- **目录**：点阅读栏顶部的「n / 总数 · 章名」，目录从阅读区左边滑出，可以按章名或序号搜索。目录里显示进度，已读的章变淡，当前章标「在读」，有总结的章带小图标。原书里「第7章」「第九章」混用，所以编号统一用左侧序号，章名去掉「第X章」前缀（一章被切成几份时保留，显示为「第一章（一）」）；楔子、番外这类标题保持原样；有卷标题的书会按卷分组。目录旁边的「笔记」页列出本书所有划线和想法，可以搜，点一条就跳过去。
- **笔记**：笔记就是你的想法，有的挂在原文上（划线时写的），有的不挂，叫随想，是读着读着冒出来的感慨。随想从阅读栏的笔记图标、目录的「笔记」页或书详情的「笔记」页写，会记下写的时候读到第几节和时间，可以修改、删除。Agent 能检索所有笔记，但不能写。
- **划线和想法**：在正文里选中文字（可以跨段落），上方弹出工具条：划线、写想法、复制、问 Agent。「问 Agent」会把这段原文作为引用放进输入框，接着写问题就行。点一条划线可以改想法、复制或删除。只有一种颜色；Agent 划的是虚线，有想法的划线末尾带小图标。
- **Agent 进度**：Agent 每次用 `read_chapter` 读原文，都会记下读的是哪一节（按对话、按书分别记，只记最近一次）。输入框上方会出现「跳到 Agent 在读的第 n 节」，点一下阅读区跳到那一节；目录里那一节标「Agent」。`book_toc` 也会告诉 Agent 它上次读到哪。
- 一个对话对应一本书，阅读位置随对话保存。
- 阅读对话的工作区是 `library/` 目录，所以 Agent 也能直接 grep 原文。

## 书的存放与 Agent 工具

导入时由程序自动分章，每本书一个文件夹：

```
library/<书名>/原文.txt          导入的原文，不改动（EPUB、PDF 是 原文.epub、原文.pdf）
library/<书名>/目录.json         每节的标题、文件名、字数
library/<书名>/章节/0001 ….txt   分好的章节
library/<书名>/总结/0001 ….md    Agent 写的总结，可以手改
library/<书名>/划线.json         划线、划线上的想法、随想
```

分章规则：
- 按「第X章/回/节/卷」、序章、楔子、番外等标题拆分。
- 卷标题后面紧跟章标题时，卷名会并进章标题。
- 单节超过 2 万字时，按段落切成约 8000 字一份，标为（一）（二）……。
- 识别不出章节标题时，整本按段落切成约 8000 字一份。
- EPUB 按书自带的目录分章（包括子目录），目录只有一项或没有时，按上面的标题规则分。
- PDF 先用书签分章；书签是扫描工具或合并文件留下的（每页一个、名字都一样）就不用，改用上面的标题规则；再没有，就把排得大、居中或者在书前目录里出现过的短行当标题。
- 直接放进 `library/` 的 TXT、EPUB、PDF 会在下次打开书库时自动转成文件夹，已有对话的绑定也跟着改过去。

阅读对话里，Agent 有这些工具：

| 工具 | 作用 |
| --- | --- |
| `book_toc` | 目录、每节字数、哪些节已有总结、用户读到第几节 |
| `read_chapter(n, offset?)` | 读第 n 节原文，每次最多 1.2 万字，长章节用 offset 翻页 |
| `save_summary(n, summary)` | 把第 n 节的总结写进 `总结/` 文件夹（覆盖旧的） |
| `read_summaries(from, to)` | 批量读总结，用来回顾前情 |
| `show_passage(n, quote)` | 让阅读区跳到第 n 节，高亮并滚动到这段原文；原文对不上就报错、不跳转 |
| `add_highlight(n, quote)` | 给第 n 节的一段原文划线。只在用户要求时划，只标原文、不写笔记 |
| `find_highlights(query?, from?, to?)` | 检索划线和你的笔记（包括随想），按关键词和节范围筛，能分出是你划的还是 Agent 划的 |
| `remove_highlight(id)` | 删除一条划线 |

划线按书存在 `library/<书名>/划线.json`，你和 Agent 划的都在里面，换个对话也能查到，也可以手改。每条记着原文、位置和前后各十几个字，书重新分章后也能找回原文。章节的换行统一按 `\n` 计，CRLF 的书和 LF 的书位置一致。

总结由主 Agent 自己读完原文后写。

你说「带我去看某段情节」时，Agent 先用 grep 或 `read_chapter` 找到原文，再调 `show_passage`。阅读页对当前对话的绑定做长轮询（`/api/dsh-reader/watch`），所以工具一执行，中间就会跳过去。自己翻页时高亮会清掉。

## Agent 怎么知道你在读什么

- **系统提示词**里只写「怎么陪读」：工具怎么用、不剧透之类。不写书名和章节，所以换书、翻页都不会打破提示词缓存。
- **阅读位置**在每轮回复开头作为一条消息追加，比如 `【阅读位置】用户此刻在读《待李子成熟时》第 4/86 节「第四章 空烛独自流」`。它通过 `agent/pre-step` 钩子插在缓存前缀之后，和酒馆追加变量变化的做法一样。
- 没翻页时不重复发：先查会话当前的上下文（压缩之后的），里面最新一条位置提示和现在一样就跳过；压缩把它丢掉了就会重新发。
- **一个对话可以读多本书**：书库里点「换到这本」在当前对话里换书，点「新开」另开对话。每本书各自记住读到哪，换回来接着读。
- 手机上右栏会全屏，所以不会自动弹出对话。

阅读会话单独存放在 `~/.dsh/profile-data/reader/`，不会混进你其他 DSH profile 的会话列表。

## 原理

- 中栏：插件以更高优先级（`priority: -10`）覆盖 ui-conversation 的 `main.conversation` 座位。没开书的会话照常渲染原生对话。
- 右栏：注册一个侧栏标签类型，标签里渲染 `conversation.content` 工厂的 `embedded` 版本。这和 DSH 子 Agent 侧栏对话用的是同一套机制。
- 每个会话只有一个输入框编辑器（Lexical），同一时刻只能挂在中栏或右栏其中一处。所以绑定状态还没读到时中栏什么都不渲染。
- 左侧栏：以更高优先级覆盖 `sidebar.workspaces` 座位，做法和酒馆一样。「开始阅读」的流程是：用 `workspaces.create({ path: library })` 拿到工作区，再 `sessions.create` 新建会话，先绑定书，等会话出现在列表里，最后 `uiWorkspace.openSession`。
- 宿主侧：
  - `/api/dsh-reader/*` 路由负责读书库、导入、按「第X章」等标题分章、保存会话与书的绑定（`data/sessions.json`），以及性格设置（`data/settings.json`）。
  - `system-prompt/assemble` 钩子只对绑定了书的会话生效，加入工作台性格和「正在读的书」两段。这两段只在换书或换性格时才变，所以不会打破提示词缓存。

## 已知限制（原型）

- 只支持 TXT、EPUB 和 PDF；分章只用规则，没有 Agent 兜底。
- PDF 要装 poppler（`brew install poppler`），用它的 `pdftotext` 抽文字。按版面把折行拼回段落，去掉页码和每页重复的页眉、页脚、水印。表格、公式、脚注会排乱。
- 扫描版 PDF（只有图片，没有文字）用 macOS 自带的文字识别（Vision）转成文字，约 1 秒一页，导入按钮上显示进度。第一次用要编译识别工具 `plugin/ocr.swift`（要有 Xcode 命令行工具），编译结果缓存在 `~/Library/Caches/dsh-reader/`。会有少量错字；竖排的书识别不好。
- 旧版按「开篇」单独成节，改成文件夹后开篇并入第一章，所以旧对话记录的阅读位置可能差一节。
- 右栏宽度沿用 DSH 默认（首次打开占 45%），需要手动拖动调窄。
- Agent 不知道你读到了哪一节（防剧透和「当前章节」工具还没做）。
- 工作台性格只能选内置的或者改内置的，还不能新建自定义性格。
